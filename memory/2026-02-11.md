# 2026-02-11 - Fix State Management, Routing, and Encoding Bugs

## Summary

Fixed three root causes of intermittent "Note Not Found" errors and wrong vault after refresh:

### Bug 1: `loadedPath` guard prevents note retry after vault change (HIGH)
- **File**: `frontend/src/pages/Note.svelte`
- Added `loadedVaultId` tracking alongside `loadedPath`
- Only set both on **successful** load; reset to `null` on failure
- Changed guard to: `notePath !== loadedPath || activeVaultId !== loadedVaultId`

### Bug 2: No vault persistence across page refreshes (HIGH)
- **File**: `frontend/src/lib/stores/vault.ts`
- Added `localStorage` read/write helpers for `activeVaultId` (matching `theme.ts` pattern)
- In `loadVaults()`: check localStorage for stored vault preference; re-sync backend if needed
- In `selectVault()`: persist new vault ID to localStorage
- In `deleteVault()`: update stored vault after deletion
- In `reset()`: clear stored vault
- Added `loadVaultsInProgress` flag to prevent concurrent `loadVaults()` calls

### Bug 3: Wiki links and embeds not URL-encoded (MEDIUM)
- **File**: `backend/src/obsidian_reader/services/markdown.py`
- Added `encode_path_for_url()` helper using `urllib.parse.quote()`
- Applied to all `href` and `src` attributes in `WikiLinkInlineProcessor`, `EmbedInlineProcessor`, and `EmbedPreprocessor`

### Bug 4: Frontend component hrefs not URL-encoded (MEDIUM)
- **Files**: `FileTree.svelte`, `NoteContent.svelte`, `Search.svelte`
- Exported `encodePathForUrl` from `api.ts`
- Applied encoding in all three components
- Fixed `isActive()` in `FileTree.svelte` to compare against both encoded and decoded paths
